# setjmp and longjmp as wasm exceptions, the javascript ones cost a thrown js
# exception per cpu_loop_exit. asyncify can't instrument functions that hold
# them, so the setjmp users are kept out of it (none sit on a coroutine switch)
# and ffi_call_js is no asyncify import (tcg helpers never yield)
